# DEVETESION — PHOTOSHOOT SEQUENCE SYSTEM

**Complete system for generating cohesive, real-photographer-quality fashion photoshoot sequences.**

Every generated image looks like it was shot by a human photographer in one real-world session — not AI.

---

## Folder Structure

| File | Purpose |
|------|---------|
| `MASTER_PHOTOSHOOT_PROMPT.md` | The master prompt — combine with any look/season to generate one photoshoot image |
| `POSE_LIBRARY.md` | 30 detailed poses — one per look, designed to flow as one sequence |
| `SEQUENCE_SHOT_LIST.md` | Shot order, camera specs, and framing for each look in the sequence |
| `COLOR_GRADE_SYSTEM.md` | Film stock + color grading presets for consistency across all generated images |
| `WEB_LAYOUT_GUIDE.md` | How to arrange generated images as moodboard and web app layouts |

---

## How to Use

### Step 1: Generate Individual Look Images
Use your existing Season 12 prompts (or any season prompts) to generate 30 individual look images.

### Step 2: Apply Photoshoot Sequence Treatment
For EACH generated look image:
1. Upload the generated look image
2. Append the `MASTER_PHOTOSHOOT_PROMPT.md`
3. Append the matching pose from `POSE_LIBRARY.md`
4. Append the color grade from `COLOR_GRADE_SYSTEM.md`
5. Generate the retouched version

### Step 3: Arrange as Sequence
Use `SEQUENCE_SHOT_LIST.md` to order all 30 images.
Use `WEB_LAYOUT_GUIDE.md` to arrange them as moodboard and web app layouts.

---

## Core Principle

**Every image in the sequence must share:**
- Same photographer eye (camera angle, lens choice, framing style)
- Same location DNA (environment, lighting conditions, time of day)
- Same film treatment (grain, color cast, contrast curve)
- Same post-production approach (no AI smoothing, raw film look)

**This is what separates a photoshoot from random images.**
