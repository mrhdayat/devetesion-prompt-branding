# EXPERIMENT 07: ALGORITHMIC ART

**Skill:** `algorithmic-art`

## Objective
Buat generative visual art dari code — interactive HTML/JS yang representasi aesthetic DEVETESION.

## Test Brief

### Design Philosophy
Buat algorithmic art piece yang merepresentasikan DEVETESION brand identity:

**Visual DNA:**
- Monolithic brutalism — massive concrete structures
- Dark luxury — black, white, minimal color palette
- Water submersion — flooded runways, rippling reflections
- Flash photography — harsh direct light, deep shadows
- Architectural typography — bold, geometric letterforms

### Requirements

Generate 3 files:

1. **`.md` file** — Design philosophy document
   - Nama aesthetic movement ini
   - Prinsip-prinsip visual
   - Hubungan sama DEVETESION brand

2. **`.html` file** — Interactive viewer
   - Full-screen experience
   - Generative visual pattern
   - Interactive (mouse movement / scroll / click triggers changes)
   - Dark aesthetic (black/white/grayscale)
   - Feels expensive, editorial, architectural

3. **`.js` file** — Generative algorithm
   - Algorithm yang create visual patterns
   - Bisa incorporate: geometry, noise, grid systems, typography
   - Performance: should run smoothly at 60fps

### Creative Direction

Bukan sekadar random pattern. Harus terasa seperti:
- Standing di dalam DEVETESION fashion show venue
- Brutalist concrete cathedral flooded with black water
- Camera flash freezing water droplets mid-air
- Architectural, cold, beautiful, slightly unsettling

**Output:**
- File di: `06_SKILL_EXPERIMENTS/outputs/algorithmic-art/`
- Files: `philosophy.md`, `viewer.html`, `algorithm.js`

---

Run with: `skill: algorithmic-art`
