# EXPERIMENT 05: CONTENT STRATEGY

**Skill:** `content-strategy`

## Objective
Buat editorial roadmap dan topic cluster strategy untuk DEVETESION.

## Test Brief

### Part A: Topic Clusters
Buat content pillar + cluster strategy untuk DEVETESION:

**Pillar Topics** (3-4 topik utama yang jadi authority):
- Example: "Avant-Garde Fashion", "Dark Luxury Aesthetic", "Motorsport Couture"

Untuk setiap pillar:
- 5-8 cluster articles/content pieces
- Internal linking strategy antar cluster
- Content gap analysis (apa yang belum ada)

### Part B: Editorial Roadmap
Buat 90-day content calendar:

**Month 1: Foundation**
- Core content pieces (evergreen)
- Brand building content

**Month 2: Engagement**
- Interactive/engagement-driving content
- Community building

**Month 3: Conversion**
- Content yang drive action (follow, share, engage)
- Campaign amplification content

### Part C: Content Mix
Define content type ratio:
- Educational (behind-the-scenes, technique, process)
- Inspirational (moodboard, campaign stories)
- Promotional (product drops, lookbooks)
- Community (user-generated, collaborations)

**Brand Context:**
- DEVETESION: Luxury fashion brand, dark aesthetic
- Current: Instagram + web
- Target: Creative class, 18-35
- Goal: Build brand authority + engaged community

**Output Format:**
- Markdown table untuk calendar
- Bullet list untuk clusters
- Clear priorities (what to do first)

---

Run with: `skill: content-strategy`
