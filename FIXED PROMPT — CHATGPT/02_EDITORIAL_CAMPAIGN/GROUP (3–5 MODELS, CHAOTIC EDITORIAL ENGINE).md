================================
GROUP DYNAMICS ENGINE (CORE)
============================

CRITICAL:
This is NOT a group photo, NOT a team pose, NOT symmetrical.

This is HIGH-FASHION EDITORIAL CHAOS:

- imbalance
- layering
- interruption
- hierarchy
- visual tension

---

COMPOSITION STRUCTURE (RANDOM PER GENERATION):

1. LAYER STACK:
   - subjects arranged in depth (foreground / mid / background)
   - partial occlusion between bodies

2. FRAGMENTED CLUSTER:
   - group broken into uneven clusters (2 + 1 + 1, etc)
   - visual separation within same frame

3. COLLISION FIELD:
   - bodies placed close but awkwardly spaced
   - near contact without clean interaction

4. DOMINANT FIGURE:
   - one subject dominates frame
   - others partially visible or cropped

5. EDGE DISTRIBUTION:
   - subjects pushed toward frame edges
   - center intentionally empty or minimal

---

SPACING RULES:

- NEVER evenly spaced
- NEVER symmetrical left/right
- subjects may:
  • overlap
  • block each other
  • be partially hidden
  • enter/exit frame
