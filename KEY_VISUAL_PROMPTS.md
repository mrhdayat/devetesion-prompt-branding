# DEVETESION — KEY VISUAL PROMPTS

**Master collection of ready-to-use image generation prompts for AI image generators (FLOW by Google, Midjourney, DALL-E, etc.).**

Every prompt below is copy-paste ready. Upload model photos + paste the prompt.

---

## HOW TO USE

### Step 1: Upload Model Photos
Upload 1-6 model photos. Each photo = one distinct person in the output.

### Step 2: Choose Your Prompt
Pick ONE prompt from the sections below:
- **Section A**: DEVETESION Original Campaigns (our own brand aesthetic)
- **Section B**: Real Brand Style References (Balenciaga, Rick Owens, etc.)
- **Section C**: Photoshoot Environments (studio, outdoor, indoor architectural)

### Step 3: Add Modifiers (Optional)
Append ONE typography overlay + ONE lighting modifier from Section D.

### Step 4: Generate
Paste into FLOW by Google, Midjourney, or your AI image generator.

## PART 0: IDENTITY LOCK — PREPEND TO EVERY PROMPT

**This block MUST be at the top of every prompt. It ensures model faces and outfits are preserved.**

```
STRICT IMAGE PRESERVATION MODE (ABSOLUTE — NO EXCEPTION):

- ANALYZE each uploaded image as a SEPARATE INDIVIDUAL.
- DO NOT merge, blend, average, or combine identities under any circumstance.
- Each uploaded image = ONE DISTINCT HUMAN MODEL.
- DO NOT generate new faces or identities.
- DO NOT alter facial structure, expression, skin texture, or identity in ANY way.
- DO NOT modify, restyle, or reinterpret outfits. Keep garments EXACTLY as they are.
- DO NOT apply artificial beauty filters or "AI face smoothing".

IDENTITY LOCK:
- Every model MUST appear as a FULL, SEPARATE BODY in the final image.
- Each face must be clearly visible and recognizable.
- NO overlapping that hides identity.
- NO fusion of bodies, faces, or outfits.

HARD RULE:
If 5 images are uploaded → there MUST be 5 DISTINCT HUMANS visible.
If 1 image is uploaded → there MUST be 1 HUMAN visible.

ANTI-MERGE:
- NEVER combine multiple references into one person.
- NEVER reduce the number of people.
- NEVER duplicate the same person to fake count.

If identity blending occurs → OUTPUT IS INVALID.
```
