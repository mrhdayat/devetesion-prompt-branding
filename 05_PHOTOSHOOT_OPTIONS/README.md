# DEVETESION PHOTOSHOOT OPTIONS

Three distinct photoshoot environment options for multi-model group editorial shots.

## How to Use

1. **Upload multiple model photos** (e.g., 5 model images with Devetesion outfits)
2. **Choose ONE of the three options below** based on your desired vibe
3. **The prompt will merge ALL models into a single cohesive frame** within the chosen environment

---

## 📸 Option A: Clean Photo Studio
**File:** `OPTION_A_CLEAN_STUDIO.md`

- Professional, polished studio environment
- Cyclorama walls, canvas backdrops, minimalist studio spacing
- Conceptual props: designer tables, modern sofas, chrome stools, plexiglass plinths
- Best for: clean, controlled, high-end editorial look

---

## 🌆 Option B: Outdoor Location
**File:** `OPTION_B_OUTDOOR_LOCATION.md`

- Real outdoor locations with architectural/urban elements
- Rooftop parking, concrete plazas, pedestrian bridges, heritage courtyards
- Models interact with railings, stairs, walls, pavement, structures
- Best for: grounded, realistic, Vogue/Dazed campaign feel

---

## 🏛️ Option C: Indoor Architectural Room
**File:** `OPTION_C_INDOOR_ARCHITECTURAL.md`

- High-end interior architecture with three routes:
  - **Avant-Garde Modernist:** travertine, plaster, marble, frosted glass
  - **Heritage Mansion:** mahogany, ornate ceilings, brass handrails
  - **Designer Loft:** industrial windows, white brick, contemporary art plinths
- Models interact with architectural props: sofas, fireplaces, rugs, partitions
- Best for: ultra-expensive destination campaign shoot

---

## Rules Applied to All Options

✅ **STRICT IMAGE PRESERVATION** — No face/outfit changes
✅ **MODEL COUNT MATCH** — Output models = uploaded images count
✅ **SEAMLESS MERGE** — All models in ONE cohesive frame
✅ **EDITORIAL BODY LANGUAGE** — No mannequin poses
✅ **HIGH-RESOLUTION OUTPUT** — Raw photo, 8k quality
